# android_device_samsung_a5y17lte - DutchOS 1.0 🇳🇱

Trotse opensource Android 14 (LineageOS 21 base) device tree voor de **Samsung Galaxy A5 (2017)** (*a5y17lte*), ontwikkeld in Heerlen, Nederland!

| Project | Specificatie / Feature | Status / Integratie |
| :--- | :--- | :--- |
| **OS Naam** | DutchOS v1.0 Premium | ✅ Volledig gebrand in build.prop |
| **Android Base** | Android 14 (LineageOS 21) | 🚀 Ultra-lightweight AOSP clean |
| **GApps** | NikGApps Basic | 📦 Play Store + Services geïnjecteerd |
| **Architectuur** | ARM64 (Exynos 7880) | 🪛 Geoptimaliseerd voor Vulkan 1.3 |
| **Opslag** | 256 GB Base + MicroSD | 💾 Uitbreidbaar tot 2 TB (2048 GB) |

## Hoe te compileren op Linux Mint 🐧
```bash
. build/envsetup.sh
breakfast a5y17lte
brunch a5y17lte
```
